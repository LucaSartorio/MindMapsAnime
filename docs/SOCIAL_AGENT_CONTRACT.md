# Social Agent Contract

> The contract between a **content agent** (e.g. a future ChatGPT agent) and the
> AniMapVerse **social-engine**. The agent chooses WHAT to produce; the engine
> validates, renders, records and refuses anything unsafe or duplicated.
> Machine-readable twin: [`tools/social-engine/schemas/social-content.schema.json`](../tools/social-engine/schemas/social-content.schema.json)
> (JSON Schema 2020-12, generated from the TypeScript types — `npm run social:schema`).
>
> No agent is connected yet (phase 2 only prepares the contract and the infrastructure).

## 1. What the agent reads

| File | What it is |
| --- | --- |
| `tools/social-engine/catalog/catalog.json` | **The menu.** Every content the engine can really render, derived from the datasets, with its history status. Regenerated by `npm run social:catalog` and after every batch. |
| `tools/social-engine/history/history.json` | Every video ever queued/rendered (one record per `renderId`): status, dates, output, attempts, last error, publication fields. |
| `tools/social-engine/catalog/excluded.json` | (optional) Subjects that can't be produced, with the reason. |

A catalog item (CharacterJourney):

```json
{
  "id": "character-journey:naruto:itachi-uchiha",
  "anime": "naruto",
  "animeTitle": "Naruto",
  "subject": "itachi-uchiha",
  "displayName": { "en": "Itachi Uchiha", "it": "Itachi Uchiha" },
  "locales": ["en", "it"],
  "recommendedDurationSeconds": 21,
  "facts": { "importance": "major", "places": 5, "animatedStops": 5, "arcs": 4 },
  "renderedLocales": ["en"],
  "publishedLocales": [],
  "queuedLocales": [],
  "renderedBefore": true,
  "publishedBefore": false
}
```

- `locales`: languages whose text really exists for this content. **Only request these.**
- `facts.places` = places in the whole journey; `animatedStops` = places shown (long journeys are sampled).
- `displayName` differs by language for some characters (One Piece: Luffy / **Rufy**): use the right one in a hook.
- `renderedLocales` / `queuedLocales` / `publishedLocales`: what already exists → avoid it (see §5).

## 2. What the agent writes

**One JSON object per content**, either:

- as a file in `tools/social-engine/content/queue/` (name: `[A-Za-z0-9][A-Za-z0-9._-]*.json`, e.g.
  `0042-naruto_sasuke-uchiha_character-journey_en.json`; files are rendered in **name order**), or
- as an **array** of objects in one file, enqueued with
  `npm run social:queue -- --from proposal.json` (each item validated + de-duplicated, then written
  to the queue as a canonical file with every default made explicit). **Preferred.**

### Required fields

| Field | Type | Rule |
| --- | --- | --- |
| `template` | string | `"characterJourney"` (alias `"character-journey"`) |
| `anime` | string | catalog `anime` (`naruto`, `onepiece`, `hunterxhunter`, `dragonball`, `blackclover`); URL slugs (`one-piece`, `hunter-x-hunter`, `dragon-ball`, `black-clover`) also accepted |
| `subject` | string | catalog `subject` (e.g. `itachi-uchiha`). Ids (`char-itachi`) and **unique** short forms (`luffy`) are accepted and normalized |

### Optional fields

| Field | Type | Default / rule |
| --- | --- | --- |
| `locale` | `"en"` \| `"it"` | `"en"`. Must be in the item's `locales` |
| `hook` | string, 1–90 chars | EN `Follow {name}'s journey across the {anime} world.` · IT `Segui il viaggio di {name} nel mondo di {anime}.` Keep it ≤ ~70 chars (2 lines on a phone). Write it in the video's `locale` |
| `cta` | string, 1–80 chars | EN `Explore the full journey on AniMapVerse` · IT `Esplora il percorso completo su AniMapVerse` |
| `durationSeconds` | number 12–60 | 22. Prefer the item's `recommendedDurationSeconds` |
| `variant` | slug `[a-z0-9-]`, ≤ 80 | none. **Required for a new edition** of a video that already exists (same content + locale) |
| `notes` | string ≤ 500 | why this content was chosen (stored, never rendered) |
| `id` | `"<template>:<anime>:<subject>"` | catalog `id`. If present it must match the other fields |
| `status` | `"queued"` | only this value is allowed (the engine owns every other state) |
| `journey` | `{ routeIds?, includeEvents?, maxStops? }` | expert tuning; **agents should omit it** |
| `highlights` | string[] ≤ 5 | recap locations; must be stops of the journey; **agents should omit it** |
| `audio` | `{ src, volume? }` | local royalty-free file in `tools/social-engine/audio/`; **agents must omit it** |
| `allowRerender` | boolean | **human override only — agents must never set it** |
| `$schema` | string | ignored |

Any other field is an **error** (typos are never silently ignored).

### Enums

- `template`: `characterJourney`
- `locale`: `en`, `it`
- `anime`: `naruto`, `onepiece`, `hunterxhunter`, `dragonball`, `blackclover` (+ URL slugs)
- `status` (input): `queued`
- history `renderStatus`: `queued` → `rendering` → `rendered` | `failed` (`failed` → `queued` on retry)
- history `publicationStatus`: `notPublished` | `partiallyPublished` | `published` (reserved; nothing publishes yet)
- platforms (reserved): `youtube`, `tiktok`, `instagram`

## 3. Examples

Minimal:

```json
{ "template": "characterJourney", "anime": "naruto", "subject": "sasuke-uchiha" }
```

A typical agent response (array, for `social:queue -- --from`) —
[`tools/social-engine/examples/agent-response.json`](../tools/social-engine/examples/agent-response.json):

```json
[
  {
    "template": "characterJourney",
    "anime": "naruto",
    "subject": "sasuke-uchiha",
    "locale": "en",
    "hook": "Sasuke never stopped running. Here's where.",
    "durationSeconds": 23,
    "notes": "Major character, 15 places, never rendered."
  },
  { "template": "characterJourney", "anime": "one-piece", "subject": "luffy", "locale": "it" },
  {
    "id": "character-journey:hunterxhunter:gon-freecss",
    "status": "queued",
    "template": "characterJourney",
    "anime": "hunterxhunter",
    "subject": "gon-freecss",
    "locale": "en",
    "variant": "father-quest",
    "hook": "Gon crossed the world to find one man.",
    "cta": "Explore the full journey on AniMapVerse"
  }
]
```

```json
{
  "$schema": "../../schemas/social-content.schema.json",
  "id": "character-journey:naruto:itachi-uchiha",
  "status": "queued",
  "template": "characterJourney",
  "anime": "naruto",
  "subject": "itachi-uchiha",
  "locale": "en",
  "durationSeconds": 22,
  "hook": "Follow Itachi Uchiha's journey across the Naruto world.",
  "cta": "Explore the full journey on AniMapVerse"
}
```

## 4. Identity

| Name | Format | Example |
| --- | --- | --- |
| content id | `<template>:<anime>:<subject>` | `character-journey:naruto:itachi-uchiha` |
| render id (one video) | `<contentId>@<locale>[+<variant>]` | `character-journey:naruto:itachi-uchiha@en`, `…@it+teaser` |
| files | `<anime>_<subject>_<template>_<locale>[_<variant>]` | `naruto_itachi-uchiha_character-journey_en.mp4` / `.manifest.json` |

Ids never depend on the date, the hook or the CTA; the content id doesn't depend on the language.
All segments are lowercase slugs, so no id can contain a path.

## 5. Duplicate policy

The unit of uniqueness is the **render id** (content + locale + variant).

| Situation | Result |
| --- | --- |
| same render id already in the queue | **rejected** (`duplicate: … already queued`) |
| same render id already rendered (or published) | **rejected** (`duplicate: … already rendered`) → use a new `variant` for a genuinely new edition |
| same render id previously **failed** | accepted (it's a retry) |
| same content, other locale or other variant | accepted, with a note (`same content already rendered as: en`) |
| two items of one proposal with the same render id | the first is accepted, the second rejected |

Agent guidance: prefer items with `renderedBefore: false` and no `queuedLocales`; don't propose
a `variant` of something rendered recently unless the angle (hook) is genuinely different.

## 6. Errors (what the engine answers)

`npm run social:queue -- --from …` prints one verdict per item and exits 1 if any is rejected;
`npm run social:validate:queue` does the same for files already in the queue. Typical errors:

| Error | Meaning / fix |
| --- | --- |
| `template: unknown template "x"` | use `characterJourney` |
| `anime: is required` / `Unknown anime "pokemon". Available: …` | use a catalog `anime` |
| `character "gon-frecss" not found … Did you mean: gon-freecss` | use the catalog `subject` |
| `journey data missing for character "x"` / `only one place on the map` | subject not in the catalog |
| `locale: must be one of: en, it` | only `en`/`it` |
| `durationSeconds: must be between 12 and 60` | |
| `hook: must be at most 90 characters` | shorten |
| `foo: unknown field` | remove it |
| `status: when present must be "queued"` | |
| `id mismatch: the config describes "…" but id says "…"` | omit `id` or copy it from the catalog |
| `duplicate: … already queued / already rendered` | see §5 |

Files dropped directly in the queue that fail validation are moved by the batch to
`content/failed/` with a `<file>.error.json` (`kind`: `invalid` | `data` | `duplicate` | `render`) —
never deleted.

## 7. What happens next (engine side)

```
queue/*.json ─► social:render:queue ─► output/<stem>.mp4 + <stem>.manifest.json
                     │                    content/rendered/<file>.json
                     │                    history: rendered
                     └─ failure ────────► content/failed/<file>.json + .error.json
                                          history: failed (lastError) ─► social:retry:failed
```

The agent never renders, moves files, edits history or publishes.
