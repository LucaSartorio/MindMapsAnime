# tools/social-engine — INTERNAL ONLY

Private Remotion renderer for vertical social videos built from the AniMapVerse
datasets. Not part of the public site (no routes, UI or endpoints).

```bash
npm run social:validate
npm run social:render -- --config tools/social-engine/examples/itachi-character-journey.json
npm run social:studio
```

Full documentation: [`docs/SOCIAL_ENGINE.md`](../../docs/SOCIAL_ENGINE.md).
